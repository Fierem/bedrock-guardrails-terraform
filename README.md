## About the Session

Configuring generative AI security controls manually through a cloud console can introduce configuration drift and make policy changes difficult to track.

This project explores how **Terraform** can be used to codify **Amazon Bedrock Guardrails** as version-controlled infrastructure, with a focus on reproducible and testable AI security controls.

The session covers topics including:

* Deploying Amazon Bedrock Guardrails with Terraform
* Configuring sensitive-information and PII protections
* Configuring prompt-attack protections
* Managing guardrail configuration as Infrastructure as Code
* Testing guardrail behavior against example payloads in AWS
* Reducing configuration drift through version-controlled infrastructure
